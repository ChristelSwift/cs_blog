Estimating reach and frequency using pmvnorm

Using the cumulative multivariate normal distribution to estimate reach and frequency.

Abstract

In a previous article, I showed how to use a simulation from a Gaussian copula to re-create the multivariate distribution of consumed units (time spent, number of films watched etc…) across a population. In this post, we will see how the same can be done using the multivariate Normal cumulative distribution function.

In a previous post, I showed how we can use some marginal distributions (e.g. separate media measurements) and link them with a correlation matrix to derive an estimate of combined reach using a Gaussian copula. This was done by creating a simulation of 100k data points from the Gaussian copula and by mapping the resulting Normal margins to the observed margins using their quantiles. Then we can simply analyse results based on that simulated dataset and get cross media reach for any time spent threshold, as well as the solus reach from each media.

In this post I will show how we can also do this without simulating a dataset, just by using the multivariate Normal cumulative distribution. As it doesn’t have a closed form solution, we will use the convenient pmvnorm function from the mvtnorm package to estimate the probability \(P(X_1 \in [l_1, u_1], ... , X_n \in [l_n, u_n])\). This function implements the methodology described in (Genz 1992).

First I will show how to use the quantile distribution in the univariate case, then the bivariate case using a simulated dataset, and finally using the Bacon and Eggs dataset.

1 simulated univariate example

In this previous post, we turned a multivariate continuous simulation into discrete values. To get the probability that our multivariate distribution is in a specific region, for example \(P(X_1 = 0, ... , X_n = 0)\), we then used the results from the simulated transformed dataset, but this can also be done using the quantiles of the cumulative continuous distribution.

In this section we will take the simple example of one variable to demonstrate how we map the values from a random sample from \(N(0,1)\) onto any observed discrete distribution. Then we will show how to correctly set the bounds of a region of interest with discrete values.

Let’s start with a random sample from a Poisson distribution. We will: - derive their observed cumulative distribution,
- create a simple univariate normal simulation and
- transform it by mapping its continuous values to the observed quantiles in exactly the same way as before.

Note that when we simulate a cross-media dataset from currencies we will not have an observed full dataset, just some observed margins from separate datasets and an empirical correlation matrix from a separate study. The steps described below with the univariate case will seem overly complicated but their only purpose is to illustrate how to correctly set the bounds of the cumulative distribution. When we move to the multivariate case, this will help to understand how to correctly define the marginal regions of the cumulative multivariate normal distribution.

The mapping process:
Given an observed cumulative distribution \(F(X)\), we map the \(p_k = F(X = k)\) to the \(N(0,1)\) cumulative distribution:

# extend observed cumulative distribution so that F(X) starts at zero:
x <- c(-1, actual_distr$value)
y <- c(0, actual_distr$cumpc)

# observed cumulative distribution:
p1 <- data.frame(x, y) %>% 
  ggplot(aes(x = x, y = y)) + 
  geom_step(col = "hotpink") + 
  expand_limits(y = 0) +
  geom_vline(xintercept = 8, col = "lightgray") +
  geom_hline(yintercept = 1, col = "lightgray") +
  geom_hline(yintercept = actual_distr$cumpc, col = "lightgray", linetype = "dashed") +
  scale_y_continuous(breaks = actual_distr$cumpc[1:6]) +

p2 <- simdata %>%

For example we see that on the left hand side, the first value corresponding to \(P(X = 0)\) is \(p = F(X) = 0.1367\), i.e. 13.67% of the observed dataset has the value 0. This is our first critical value: in our simulated dataset on the right, we have to find the value of \(z\) such that \(p = \Phi(Z)) = 0.1367\). To do this we use the quantile function which is the inverse of the cumulative distribution function, i.e. for a given cumulative percentage on the y axis, the quantile function gives the corresponding value on the x axis.

quantile(simdata$value, probs = 0.1367)
   13.67% 
-1.119935

so any data point below this threshold in our simulated dataset will be assigned the value of zero: this way, 13.67% of our mapped dataset will be zero, just like in our observed dataset.

The second step on the right hand side corresponding to \(P(X \leq 1)\) is \(p = F(X) = 0.4057\).
In our simulated dataset, we have to find the value of \(z\) such that \(p = \Phi(Z)) = 0.4057\):

quantile(simdata$value, probs = 0.4057)
    40.57% 
-0.2364882

so any data point between the 1st and 2nd threshold in our simulated dataset will be assigned the value of 1, etc until we’ve exhausted all possible values of X.

The full list of thresholds that we have to apply to the simulated \(N(0,1)\) is given by:

quantile(simdata$value, actual_distr$cumpc)
    13.67%     40.57%     67.59%     86.01%     94.98%     98.47%     99.56% 
-1.1199352 -0.2364882  0.4550850  1.0847586  1.6398703  2.1387512  2.5406376 
    99.89%       100% 
 3.0142916  4.0495128

(Note that we use the quantile function rather than pnorm because we are working with a dataset rather than the underlying distribution.)

Now we map the cumulative distributions of this simulated \(N(0,1)\) to the observed cumulative distributions:

# make copy so we can replace each column with their corrected values:
s <- simdata$value

# Find the critical values so we can map the simulated values to these probabilities:
crv <- c(-Inf, quantile(s, actual_distr$cumpc))

# Cut the simulated normal data according to the breaks given by the crv table:
temp <- cut(
    s,
    right = FALSE,
    include.lowest = FALSE,

Now say we want to calculate the probability that \(X \in [1,2]\):

actual_distr %>% 
  mutate(lead_value = lead(value)) %>% 
  select(value, lead_value, pc, cumpc) %>% 
  head()
  value lead_value     pc  cumpc
1     0          1 0.1367 0.1367
2     1          2 0.2690 0.4057
3     2          3 0.2702 0.6759
4     3          4 0.1842 0.8601
5     4          5 0.0897 0.9498
6     5          6 0.0349 0.9847

Looking at the observed cumulative distribution \(F(X)\), this would be the area corresponding to \(\text{cumpc} \leq 0.676\) minus \(\text{cumpc} \leq 0.137\):

\[P(X \in [1,2]) = P(X\leq 2) - P(X=0) = F(X=2) - F(X=0)\] Let’s write the thresholds for \(X\):

thresholds <- data.frame(
  name = "x",
  lower_value = 1,
  upper_value = 2
)

thresholds
  name lower_value upper_value
1    x           1           2

I added the lead value to show that this \([1,2]\) region corresponds to the interval between the lead_value = 1 and the value = 2, see in the filter step below:

# find the observed cumulative % corresponding to the lower and upper values:
quantile_bounds <- actual_distr %>% 
  mutate(name = "x") %>% 
  mutate(lead_value = lead(value)) %>% 
  inner_join(
      thresholds,
      by = "name"
      ) %>% 
    filter(
      # we need the x value of the actual_distr that is just before the x value 
      # corresponding to the lower_value:
      lead_value >= lower_value,
      value <= upper_value
      ) %>% 
    group_by(name, lower_value, upper_value) %>% 
    summarise(
      lower_cumpc = min(cumpc),
      upper_cumpc = max(cumpc)
    ) %>% 
    mutate(
      lower_cumpc = ifelse(lower_value <= 0, 0, lower_cumpc)
    )

quantile_bounds
# A tibble: 1 × 5
# Groups:   name, lower_value [1]
  name  lower_value upper_value lower_cumpc upper_cumpc
  <chr>       <dbl>       <dbl>       <dbl>       <dbl>
1 x               1           2       0.137       0.676

In the univariate case, the answer is simply the difference between upper_cumpc and lower_cumpc, ie \(P(X \in [1,2]) = 53.9\%\). When we move to the multivariate case this step will give us the required lower and upper bounds of the cumulative distribution of each observed discrete margin, and it will then make use of the correlation to estimate the corresponding cumulative multivariate distribution.

Let’s put this into a function and compare actual, simulated and pmvnorm results for all possible pairs of values:

deduplicated_reach_fc <- function(thresholds, actual_distr, sigma){
  
  #' Calculate the probability of being in a region 
  #' for example the joint probability that variable 1 is between 1 and 5
  #' and variable 2 is between 2 and 3:
  #' P(1 < X1 <= 5, 2 < X2 <= 3)
  #'
  #' @param thresholds dataframe with the columns name, lower_value, upper_value
  #' @param actual_distr dataframe with the columns name, value, pc and cumpc.
  #' @param sigma named matrix of the correlation between variables.
  #' @return expected probability.
  
  # get the names of the vehicles in the plan:
  my_vars <- thresholds %>% 
    count(name) %>% 
    pull(name)
  
  # get the corresponding correlation matrix:
  my_corr <- sigma[my_vars, my_vars] 
  
  # find the observed quantiles corresponding to the lower and upper values:
  quantile_bounds <- actual_distr %>% 
    group_by(name) %>% 
    mutate(
      max_value = max(value),
      lead_value = lead(value)
      ) %>% 
    inner_join(
        thresholds,
        by = "name"
        ) %>% 
      filter(
        # we need the x value of the actual_distr that is just before the x value 
        # corresponding to the lower_value:
        lead_value >= lower_value,
        value <= upper_value
        ) %>% 
      group_by(name, lower_value, upper_value, max_value) %>% 
      summarise(
        lower_cumpc = min(cumpc),
        upper_cumpc = max(cumpc)
      ) %>% 
      mutate(
        lower_cumpc = ifelse(lower_value <= 0, 0, lower_cumpc),
        upper_cumpc = ifelse(upper_value >= max_value, 1, upper_cumpc)
      ) %>% 
    # find the corresponding quantiles in N(0,1):
      mutate(
        lower_phi_quantile = qnorm(lower_cumpc), 
        upper_phi_quantile = qnorm(upper_cumpc) 
      )
    

  region_prob <- pmvnorm(
      lower = quantile_bounds$lower_phi_quantile,
      upper = quantile_bounds$upper_phi_quantile,
      mean = rep(0, length(my_vars)),
      corr = my_corr
    )
    
  return(region_prob[1])
  
}

  labs(title = "actual vs pmvnorm pairs of log values")

In the context of an advertising campaign, we could imagine that the products are in fact channels, and the values are the number of impacts. Then the reach and frequency of the campaign would be fully defined by just summing values across the products:

compare %>% 
  pivot_longer(actual:pmvnorm, names_to = "source") %>% 
  mutate(impacts = bacon + eggs) %>% 
  group_by(source, impacts) %>% 
  summarise(pc = sum(value)) %>% 
  ggplot(aes(x = impacts, y = pc, fill = source)) +
  geom_bar(stat="identity", position = "dodge") +
  scale_fill_manual(values = c("slateblue", "lightpink")) +
  scale_x_continuous(breaks = 0:8) +
  scale_y_continuous(labels = scales::percent) +
  geom_text(
    aes(label=scales::percent(pc, accuracy = 1, fill = source)),
    position = position_dodge(width = 0.8),
    vjust = -0.2, size = 2.5) +
  labs(title = "actual vs pmvorm frequencies") +
  theme(legend.position = "bottom")

The full distribution of the number of products bought is perfectly preserved.

4 Conclusion

In this post we saw that given just their marginal distributions and a correlation matrix we can recover the entire reach and frequency distribution of a multivariate dataset using the appropriate bounds of the multivariate normal cumulative distribution. This approach is an elegant and stable alternative to creating a simulated dataset.

In the context of cross media measurement, it can be used to estimate the cross media reach using the industry standard measurement for each media (i.e. the media currencies), and a correlation matrix from a separate single-source study.
